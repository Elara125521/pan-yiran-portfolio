# Portfolio Interaction System


## Concept

Window represents my creative world.
Moon represents user exploration.
Islands represent projects.


## Loading Animation

Sequence:

1. Window appears
2. Project element appears inside window
3. Window closes
4. Background changes
5. Moon appears


## Hero Animation

1. Text "I TURN IDEAS INTO EXPERIENCES"
   appears.

2. Text melts into liquid.

3. Liquid flows into window.

4. Window expands.

5. Liquid becomes islands.


## Project Interaction

Default:
- islands are inactive
- grey color


Hover:
- island expands
- color appears
- cursor changes


Click:
- open project detail
- show sidebar
